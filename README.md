# Microsoft 365 Fundamentals

## End User Guides
Practical user-facing guides for common Microsoft 365 applications, providing clear instructions, useful shortcuts, and everyday tips designed to help end users work more effectively and resolve common issues independently.

### [Microsoft Outlook](https://github.com/kierannutt123/Microsoft-Outlook/tree/main)
Used to manage email, calendars, contacts, and scheduling.

### [Microsoft Word](https://github.com/kierannutt123/Microsoft-Word)
Used to create, edit, format, and collaborate on documents.

### [Microsoft Excel](https://github.com/kierannutt123/Microsoft-Excel/tree/main)
Used to organise, calculate, analyse, and visualise data using spreadsheets.

### [Microsoft Teams](https://github.com/kierannutt123/Microsoft-Teams/tree/main)
Used for workplace messaging, meetings, calls, file sharing, and collaboration.

### [Onedrive](https://github.com/kierannutt123/Onedrive)
Cloud storage used to store, synchronise, share, and access files across devices.

### [Microsoft SharePoint](https://github.com/kierannutt123/Sharepoint)
Used to create organisational sites, manage shared documents between teams, and provide centralised access to information and resources.

### [Passwords & Sign In](https://github.com/kierannutt123/Passwords-Sign-In/new/main?readme=1)
Guidance for managing passwords, authentication methods, MFA, and common sign-in issues.
